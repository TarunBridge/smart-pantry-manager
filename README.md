# Smart Pantry Manager

A Java Android application that suggests recipes based strictly on leftover
ingredients, to cut food waste.

Module: Mobile App Development 700 - Practical Assignment

## Status

Under development. Planned screens: Pantry List, Add/Edit Ingredient,
Suggested Recipes, Recipe Detail and Settings. Persistence will use SQLite
through SQLiteOpenHelper.

Setup instructions will be added once the first screens run.
